(A) inheriting from several classes  (B) creating objects  (C) bundling data with the methods that operate on it  (D) using abstract classes only

✅ **Ans: (A) a class that cannot be instantiated** — (PYQ 2023)

**2.** Abstract methods are:
(A) methods that can't be accessed from outside  (B) methods that have implementation details  (C) methods with no body, declared in an abstract class  (D) methods that can't be inherited

**3.** Which keyword declares an abstract method (Java/C#)?

✅ **Ans: (D) abstract** — (PYQ 2025)

**4.** Which kind of method has no implementation in the base class and must be overridden by derived classes?
(A) Virtual method  (B) Abstract method  (C) Sealed method  (D) Static method

**5.** What is the main purpose of an interface?
(A) to be a blueprint for creating objects directly  (B) to declare a set of methods that implementing classes must provide  (C) to define constructors  (D) to create static methods

✅ **Ans: (B) to declare a set of methods that implementing classes must provide** — (PYQ 2025)
